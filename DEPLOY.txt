ИНСТРУКЦИЯ: КАК ВЫЛОЖИТЬ ИЗМЕНЕНИЯ FileSearch (GitHub -> сервер 192.168.150.100 -> Nginx)
================================================================================

Схема:
  машина разработки --git push--> GitHub (Oakey12/FileSearch)
  сервер 192.168.150.100 --git pull + release.ps1--> Nginx :1212 /file-search/
  программы у пользователей --кнопка "Обновить"--> скачивают новую версию

Текущая версия в программе видна слева внизу окна (например, "Версия 2.9.1").
Новый номер должен быть БОЛЬШЕ текущего (формат X.Y.Z, например 2.10.0).


ЧАСТЬ 1. ОТПРАВКА КОДА В GITHUB (машина разработки, C:\Users\1108\FS\FileSearch)
--------------------------------------------------------------------------------
1. Откройте PowerShell или Git Bash в папке проекта.

2. Проверьте, что изменено:
       git status

3. Если менялся интерфейс (папка frontend\src), пересоберите его.
   Готовый frontend\dist должен попасть в коммит, на сервере Node.js нет:
       cd frontend
       npm install
       npm run build
       cd ..

4. Если менялись публичные методы Go (app.go), обновите привязки:
       wails generate module
   Wails пишет файлы с другими окончаниями строк, поэтому в git status
   изменёнными окажутся все файлы frontend\wailsjs. Проверьте реальные изменения:
       git diff --ignore-cr-at-eol --stat -- frontend/wailsjs
   Если изменений нет, откатите:
       git checkout -- frontend/wailsjs
   Если изменились только frontend\wailsjs\runtime, откатите только его:
       git checkout -- frontend/wailsjs/runtime

5. Проверьте код (всё должно быть зелёным):
       go vet ./...
       go test ./...
       cd frontend; npm test; cd ..

6. Закоммитьте и отправьте:
       git add -A
       git commit -m "Краткое описание изменений"
       git push origin main
   Вход в GitHub идёт через Git Credential Manager, пароль вводить не нужно.


ЧАСТЬ 2. СБОРКА И ПУБЛИКАЦИЯ НА СЕРВЕРЕ (192.168.150.100)
--------------------------------------------------------------------------------
Требования на сервере: Git, Go 1.25+, wails
(установка: go install github.com/wailsapp/wails/v2/cmd/wails@latest).

1. Откройте PowerShell в папке клона репозитория на сервере.

2. Уберите следы прошлой сборки, иначе git pull может отказаться работать:
       git checkout -- frontend/wailsjs go.mod go.sum

3. Подтяните код:
       git pull

4. Соберите и опубликуйте (подставьте свой номер версии и описание):
       powershell -ExecutionPolicy Bypass -File .\tools\release.ps1 -Version 2.10.0 -Notes "Что нового"

   Скрипт сам выполнит:
     - go test;
     - wails build с номером версии внутри exe;
     - расчёт sha256;
     - копирование в C:\Users\1108\nginx-1.28.3\html-filesearch\file-search\ :
         latest.json                  манифест последней версии
         file-search-2.10.0.exe       файл обновления
         FileSearch.zip               для ручной установки

   Перезапускать Nginx не нужно: он отдаёт файлы напрямую.

5. Проверка. Откройте в браузере:
       http://192.168.150.100:1212/file-search/latest.json
   В нём должна быть новая версия ("version": "2.10.0").


ЧАСТЬ 3. ОБНОВЛЕНИЕ У ПОЛЬЗОВАТЕЛЕЙ
--------------------------------------------------------------------------------
- Слева внизу нажать "Обновить" -> "Обновить и перезапустить".
- Сама программа проверяет сервер каждые 15 минут: у кнопки загорится кружок.
- Программа скачивает exe, сверяет sha256, подменяет себя и перезапускается.


ЧАСТО ВСТРЕЧАЮЩИЕСЯ ОШИБКИ
--------------------------------------------------------------------------------
"В ... есть изменённые файлы, сборка взяла бы не тот код"
    Выполните: git checkout -- frontend/wailsjs go.mod go.sum
    затем git pull и запустите release.ps1 снова.
    Если в списке ваши файлы, закоммитьте их и сделайте git push с машины разработки.

"Нет готового интерфейса frontend\dist"
    Забыли закоммитить frontend\dist (часть 1, пункт 3) или не сделали git pull.

"Не найден wails"
    go install github.com/wailsapp/wails/v2/cmd/wails@latest

"Версия должна быть вида 1.2.3"
    Указывайте три числа через точки, без букв.

git pull говорит "would be overwritten by merge"
    git checkout -- frontend/wailsjs go.mod go.sum
    и повторите git pull.

Программа пишет "Сервер обновлений недоступен"
    Проверьте, что Nginx на :1212 запущен и открывается
    http://192.168.150.100:1212/file-search/latest.json

Кириллица в .ps1 превращается в кракозябры
    Файлы .ps1 должны быть в UTF-8 с BOM (release.ps1 уже такой).
    Не редактируйте их через Set-Content / Get-Content в PowerShell 5.1.


ОТКАТ
--------------------------------------------------------------------------------
Чтобы вернуть старую версию, перепубликуйте предыдущий коммит с БОЛЬШИМ номером
(программа не обновляется "назад"): git checkout <старый коммит> и release.ps1
с номером выше текущего, затем git checkout main.
