# Поиск файлов

Быстрый поиск файлов по имени в папке и всех её подпапках для Windows 10 и 11.
Логика на Go, интерфейс на [Wails](https://wails.io) (WebView2) в духе Finder.

Программа ничего не изменяет и не удаляет: при поиске она только читает список файлов,
при предпросмотре — содержимое выбранного файла.

## Как пользоваться

1. Выберите папку: «Выбрать папку…» слева, недавняя папка из списка или папка в поле поиска.
   Подходят и сетевые диски.
2. Начните вводить имя файла — результаты появляются по мере ввода. Регистр не важен,
   «е» и «ё» не различаются, ищется вхождение: `отчет` найдёт `Отчёт за июль.xlsx`.
   Несколько слов ищутся все сразу в любом порядке (`отчет июль`), фраза в кавычках —
   целиком (`"за июль"`).
3. Чтобы искать слова **внутри документов**, переключите «Имя / Текст» в поле поиска
   (или `Ctrl+Shift+F`). Под каждым файлом появится фрагмент текста с найденными словами.
4. Выберите файл: справа откроется предпросмотр. Его ширину можно менять, потянув левую
   границу; двойной щелчок по границе возвращает исходную ширину.

| Клавиши | Действие |
| --- | --- |
| `Ctrl+F`, `/` | Перейти к полю поиска |
| `↓` в поле поиска | Перейти к результатам |
| `↑` `↓` `PgUp` `PgDn` `Home` `End` | Перемещение по списку |
| `Enter` или двойной щелчок | Открыть файл |
| `Ctrl+Enter` | Показать в Проводнике |
| Пробел | Показать или скрыть предпросмотр |
| `Esc` | Остановить поиск |
| `Ctrl+Shift+F` | Искать по имени или по тексту документов |
| `Ctrl+J` | Открыть или закрыть заметки |

Щелчок по заголовку колонки сортирует список, повторный — меняет направление.

## Поиск по тексту документов

Слова ищутся в тексте `.txt` и других текстовых файлов, Word `.docx`, Excel `.xlsx`,
PowerPoint `.pptx` и PDF. Подходит и совпадение в имени файла.

Текст документов запоминается в памяти (до 256 МБ), поэтому повторный поиск по той же
папке идёт почти мгновенно. Изменённый файл перечитывается автоматически.

Сканы PDF без текстового слоя по содержимому не находятся — в них нет текста, только картинки.

## Предпросмотр

| Тип | Что показывается |
| --- | --- |
| Текст и код (`.txt`, `.log`, `.csv`, `.json`, `.go`, …) | Текст чёрным по белому; кодировка UTF-8, UTF-16 или Windows-1251 определяется сама |
| Word `.docx` | Текст документа без оформления |
| Excel `.xlsx`, `.xlsm` | Таблица по листам, до 500 строк и 50 столбцов |
| PDF | Встроенный просмотрщик PDF (как в Edge) |
| PowerPoint `.pptx` | Текст слайдов |
| Картинки `.png`, `.jpg`, `.gif`, `.bmp`, `.webp` | Изображение |
| Остальное | Сведения о файле |

Текст читается не больше чем на 1 МБ — это защищает от зависаний на огромных файлах.
При поиске по тексту найденные слова подсвечиваются, а кнопками ˄ ˅ можно переходить
между ними; в Excel подсвечиваются ячейки.

## Заметки и холст

Кнопка с блокнотом справа от поля поиска, `Ctrl+J` или язычок у верхнего края окна
открывают шторку с двумя режимами:

- **Заметки** — как на iPhone: первая строка становится заголовком, заметки
  сгруппированы по датам, есть поиск. Удалённую заметку можно вернуть кнопкой «Отменить».
- **Холст** — карточки и связи между ними. Двойной щелчок по полю создаёт карточку,
  по карточке — правит текст. Связь тянется от кружка справа на карточке к другой
  карточке. Поле двигается мышью, масштаб — `Ctrl`+колесо. Найденный файл можно
  отправить на холст кнопкой в предпросмотре; двойной щелчок по такой карточке открывает файл.

Всё сохраняется автоматически в `%APPDATA%\FileSearch` (`notes.json`, `board.json`).

## Почему быстро

- Каталоги обходятся в несколько потоков. Особенно это заметно на сетевых дисках,
  где каждое чтение каталога ждёт сеть.
- Результаты приходят пачками по мере нахождения, а не в конце.
- Список виртуальный: на экране рисуются только видимые строки, поэтому 100 000
  результатов прокручиваются так же плавно, как 10.
- Выдача ограничена 100 000 файлов — при слишком общем запросе программа предложит его уточнить.

## Структура проекта

```text
main.go, app.go          окно Wails и методы, которые вызывает интерфейс
internal/search          многопоточный поиск по имени и тексту
internal/content         извлечение текста из документов и кэш
internal/preview         подготовка предпросмотра
internal/shell           Проводник и открытие файлов (Windows API)
internal/settings        недавние папки, заметки и холст (%APPDATA%\FileSearch)
internal/update          обновление с сервера Nginx
frontend/                интерфейс: TypeScript без фреймворков + Vite
```

## Сборка

Нужны Go 1.25+, Node.js 20+ и Wails CLI (`go install github.com/wailsapp/wails/v2/cmd/wails@latest`).

```powershell
wails dev      # разработка с горячей перезагрузкой
go test ./...  # тесты
wails build    # build\bin\file-search.exe
```

Выпуск версий и сервер обновлений описаны в [RELEASE.md](RELEASE.md).
